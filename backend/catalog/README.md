# 한국 대학 선택 목록

현재 목록은 **385개 선택 항목**입니다. 공식 원본의 학부 대학·전문대학 442개 행에서 같은 학교명의 캠퍼스를 묶고 확인된 통폐합·폐교·역사 항목을 정리했습니다. 별도 학교명으로 공개된 고려대학교(세종), 연세대학교(미래), 한양대학교(ERICA) 등은 별도 선택·집계 항목으로 유지합니다. 이를 국내 학교 수의 공식 통계로 해석하지 마세요.

- 기본 자료: 한국대학교육협의회, 공공데이터포털 [전국대학및전문대학정보표준데이터](https://www.data.go.kr/data/15107736/standard.do)
- 기준연도: **2025년**. 원본 데이터 기준일: **2026-03-18**.
- 통폐합·폐교 대조: 대학알리미 [통·폐합, 신설 및 폐교 대학 현황](https://m.academyinfo.go.kr/empty/intro/intro0351/intro.do), 확인일 **2026-10-22**.
- 해당 공개 자료의 출처 표시 조건에 따라 원 출처·제공기관·기준일·다운로드 원본 SHA-256을 universities.json의 metadata에 기록합니다.
- 대학원 단독 항목은 제외합니다. 일반대학·전문대학·교육대학·방송통신·사이버·기능·기술대학 등 원본에 수록된 학부 항목을 포함합니다.

통합된 국립강릉원주대학교는 강원대학교, 경남도립거창·남해대학은 국립창원대학교 등으로 연결하고 옛 이름을 aliases에 남깁니다. 서남대학교·한중대학교 등 확인된 폐교 항목은 제외합니다. 변경 규칙과 제외 사유는 overrides.json에 공개합니다. 성심외국어대학 등 현재 선택 명칭을 확정하지 않은 역사 항목은 가입 목록에서 제외했습니다. 원본은 현재 운영 상태 열을 제공하지 않으므로 이 목록만으로 모든 학교의 최신 운영 상태를 확정하지 않습니다. 추가 변경은 운영진이 출처를 확인해 반영하세요.

`universities.json`에는 id, name, kind, regions, aliases, campuses가 있습니다. ID는 학교명 해시에서 만든 **앱 내부 고정 ID**이며 공식 학교 코드가 아닙니다. 학교명이 바뀌는 경우 자동으로 같은 학교라고 추정하지 말고 FK와 기존 기록을 고려한 별도 매핑을 검토하세요.

## 서버 반영

서버가 기본적으로 내장 목록을 등록합니다. 기존에 같은 이름이 다른 ID로 등록돼 있다면 **기존 ID를 유지**하고 메타데이터만 보완합니다. 기존 회원·기록의 ID를 재할당하지 않습니다. 테스트용으로 목록을 넣지 않으려면 `CR_SEED_UNIVERSITIES=0`을 지정합니다. 이름이 다른 기존 ID와 해시 ID가 충돌하면 시작을 실패시키며 잘못된 학교로 덮어쓰지 않습니다.

검색 예: `/api/universities?q=강릉원주`, `/api/universities?region=서울특별시&kind=대학교`. 한글 쿼리는 URL 인코딩하세요. 원본에서 여러 지역에 캠퍼스가 있으면 어느 해당 지역으로 검색해도 표시됩니다. 통합·제외 전 회원이 이미 있는 기존 DB의 학교를 임의 삭제·통합하지는 않습니다. 그런 데이터는 백업 후 운영진이 별도 검토해야 합니다.

## 갱신

```powershell
python tools\build_catalog.py
```

공식 사이트의 공개 JSON 다운로드 버튼과 같은 경로로 내려받아 JSON과 내장 C 헤더를 생성합니다. API 키나 로그인이 필요하지 않습니다. 기존 다운로드가 있으면 `--source 파일.json`으로 재현할 수 있습니다. 변경 목록·ID·기준일을 검토하고 테스트를 실행한 뒤 서버를 다시 빌드하세요. 실행 중에 인터넷을 조회하거나 데이터를 자동 변경하지 않습니다.
